# H5 围棋（Go Game）

一个基于 HTML5 Canvas 的围棋小游戏，支持移动端（H5）与桌面浏览器。

## 功能

- **多档棋盘**：7×7、9×9、13×13、19×19
- **完整规则**：
  - 轮流落子，黑先白后
  - 提子（吃子）与气的计算
  - 禁止自杀（落子后无气且不能提子）
  - 简单打劫（不能立即提回单子）
- **双人对弈 / 人机对战**：内置一个轻量级对手（会优先提子，避免送吃）
- **中国规则 / 日本规则计目**：
  - 中国规则按面积计（数子），贴目 0.5 目
  - 日本规则按领地 + 提子计目，贴目 0.5 目
- **悔棋 / 停一手 / 新对局 / 结算目数**

## 运行方式

直接打开 `index.html` 即可（无需构建、无需依赖）。推荐用本地静态服务器预览：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 文件结构

```
index.html       页面入口
css/style.css    样式
js/go.js         围棋规则引擎（棋盘、提子、打劫、计目、悔棋历史）
js/main.js       UI 控制器与渲染、人机对战逻辑
```

## 规则说明

- 落子到已有棋子的位置被阻止。
- 落子后己方棋串若无气且无法提掉对方棋子，判定为“自杀”，被禁止。
- **打劫**：当某手棋仅提走对方一枚棋子时，对方紧接着不能在该位置提回（简单劫规则）。
- 双方连续各停一手后对局自动结束，可点击“计算目数”随时结算。

## 技术要点

- 规则引擎 `js/go.js` 将棋盘保存为扁平数组，并通过历史快照实现完整悔棋。
- 棋盘点位用 Canvas 绘制，基于 `devicePixelRatio` 保证高分屏清晰。
- 界面为响应式布局，适配手机与桌面。
