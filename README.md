# H5 围棋 (Go)

一个纯前端的 HTML5 围棋小游戏：无需构建、无第三方依赖，直接用浏览器打开 `index.html` 即可运行，适配手机（H5）与桌面。

## 功能

- **多档棋盘**：9×9、13×13、19×19
- **完整围棋规则**
  - 黑先白后、轮流落子
  - 气的计算与提子（吃子）
  - 禁止自杀（落子后无气且无法提子时禁止）
  - 简单打劫（不能立即提回单子）
- **双人对弈 / 人机对战**（内置简单 AI，优先提子、避免送吃、贴边发展）
- **中国/日本式数目**：领地计目 + 提子数 + 白方贴目 7.5 目
- **悔棋 / 停一手 / 新对局 / 数目结算**
- 响应式界面：画布随窗口自适应，支持触屏

## 运行

直接打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 规则引擎测试

核心逻辑在 `js/go.js`，为纯逻辑、无 DOM 依赖，可在 Node 中直接测试：

```bash
node --test tests/go.test.js
```

测试覆盖：提子、禁自杀、打劫、悔棋、轮次切换、结终局（连续停手）、数目结算、AI 合法落子与克隆独立性。

## 目录结构

```
index.html          页面结构
css/style.css       样式
js/go.js            规则引擎 + 简单 AI（浏览器/Node 通用）
js/main.js          画布渲染与交互
tests/go.test.js    规则引擎单元测试
docs/*.png          界面截图（Before / After）
```
