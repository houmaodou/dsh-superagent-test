# H5 五子棋（Gomoku）

一个基于 HTML5 Canvas 的五子棋小游戏，支持移动端（H5）与桌面浏览器，无需构建、无第三方依赖。

## 功能

- **标准棋盘**：15×15 标准五子棋盘，另可选 9×9、13×13
- **胜负判定**：四个方向（横、竖、两条斜线）检测五子连珠，胜者连线高亮标记
- **双人对弈 / 人机对战**：
  - 双人对弈：黑先白后，轮流落子
  - 人机对战：玩家执黑先行，内置一个基于「连子数与两端开放度」启发式评分的简单 AI
- **悔棋 / 新对局**：人机模式下悔棋会退回玩家上一手（连同电脑应手）
- **平局判定**：棋盘下满未分胜负时提示平局
- **响应式界面**，适配手机（H5）与桌面，基于 devicePixelRatio 保证高分屏清晰

## 运行方式

直接打开 `index.html` 即可，或使用本地静态服务器预览：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 文件结构

```
index.html       页面入口
css/style.css    样式
js/gomoku.js     五子棋规则引擎（落子、五子连珠、悔棋、AI 评分）
js/main.js       UI 控制器与 Canvas 渲染、触控交互
```

## 技术要点

- 规则引擎 `js/gomoku.js` 以扁平数组存储棋盘，胜负判定沿四个方向双向扫描连子数。
- AI 在已有棋子周边 2 格范围内生成候选点，综合「进攻分 + 防守分」选择最佳落点。
- 棋盘用 Canvas 绘制，`devicePixelRatio` 缩放保证高分屏清晰；使用 Pointer Events 统一处理鼠标与触控。
